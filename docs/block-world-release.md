## 이력: 구조 변경 전 개발 상태

학생 경로는 `/tree/me/plaza`, 관리자 테스트 경로는 `/tree/admin/plaza-preview`다.
관리자 테스트는 가상 친구와 로컬 상태만 사용하며 집·아바타·접속 정보를 저장하지 않는다.
학생 경로는 실제 학생 쿠키와 저장소를 확인한다. 설정이나 테이블이 없으면 안내와 503 응답을 반환하며 가상 친구로 대체하지 않는다.

이번 작업에서는 운영 Supabase, 운영 환경변수, 학생 데이터에 접근하거나 변경하지 않았다.
새 SQL은 로컬 파일로만 준비했으며 운영에 적용하지 않았다. 로컬 환경변수 파일이나 실제 인증키를 만들지 않았다.
나무·포인트·성장·보유 아이템을 변경하거나 삭제하는 SQL은 포함하지 않는다.

## 이력: 폐기된 구 구조 적용 계획 — 실행 금지

1. 구 나무 DB 광장 SQL 적용 계획은 폐기했다. 해당 파일은 삭제했으며 다시 만들어 적용하지 않는다.
2. 서버의 `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `JWT_SECRET` 설정을 확인한다. 학생 JWT의 비밀값은 로그인 사이트와 같아야 한다. 실제 값은 클라이언트·문서·로그에 넣지 않는다.
3. 프록시를 사용하는 경우 브라우저의 실제 사이트 주소가 쓰기 요청의 허용 주소와 일치하는지 확인한다. 기본 본 사이트 주소는 `https://www.themonster.kr`이며 필요하면 서버 전용 `SOCIAL_APP_ORIGIN`을 명시한다. 전달된 `x-forwarded-host`를 임의로 신뢰하지 않는다.
4. 동일 지점의 활성 학생 두 명과 다른 지점 학생 한 명으로 접속·이동·집 저장·방문·비공개 전환을 확인한다. 비공개 전환 후 방문자는 방에서 나가고 다른 지점 집·접속 정보는 조회할 수 없어야 한다.
5. 새 테이블 두 개의 RLS가 켜졌는지, `anon`·`authenticated`가 읽거나 쓸 수 없는지, 서버 서비스 역할만 접근 가능한지 확인한다.

접속 정보는 학생당 한 행이며 30초가 지난 행은 응답에서 제외한다. 한 화면은 최대 24명의 접속 정보를 받는다.
친구 목록은 한 번에 48명씩 읽는다. 실제 방 저장은 학생 쿠키에서 확인한 본인에게만 적용된다.

## 휴대폰 검증 범위와 남은 확인

위 검사는 실제 휴대폰 성능 측정이 아니다. 물리 기기에서 원활하게 작동한다는 보장은 아직 하지 않는다.
출시 전 학생들이 실제 쓰는 낮은 사양의 Android와 iPhone에서 다음 흐름을 확인한다.

- 세로·가로 화면에서 광장, 친구 목록, 옷장, 집 꾸미기의 버튼과 저장 영역이 가려지지 않는다.
- 24명 표시, 빠른 이동, 가구 배치, 옷 갈아입기를 반복해도 멈춤·브라우저 종료가 없다.
- 느린 통신·와이파이 전환·비행기 모드·백그라운드 복귀 후 무한 로딩 없이 회복한다.
- 저장 중 연결이 끊기면 성공으로 표시하지 않고 변경 중인 내용을 유지한다.
- 친구의 집 비공개 전환과 학생 로그인 만료가 화면과 서버 양쪽에 반영된다.
- 관리자 테스트의 모든 저장 동작에서 실제 학생 저장 API가 호출되지 않는다.

운영 적용과 실제 기기 검증을 마치기 전에는 개발용 미리보기로 취급한다.
