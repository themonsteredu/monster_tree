## Runtime use and limitations

`src/features/social/RoomScene.tsx` displays the room background. `src/features/social/FurnitureArt.tsx` selects and clips the furniture raster sprites, with layout rules in `RoomScene.module.css`.

The furniture atlas is 1774 × 887 pixels, with four columns and two rows:

| Row | First | Second | Third | Fourth |
| --- | --- | --- | --- | --- |
| Top | `sofa` | `rug` | `desk` | `bed` |
| Bottom | `plant` | `shelf` | `lamp` | Empty |

Although the prompt requested transparency, the generated atlas is an RGB PNG with a painted checkerboard background, not an alpha-transparent PNG. A background-extraction retry (`exec-ef5cd264-b49a-4fce-ac4e-2738d2e1f87a.png`) also lacked alpha and was not selected. The implementation therefore uses explicitly approved CSS `clip-path: polygon(...)` silhouette crops at runtime. These are display masks, not vector replacement artwork or modified image files. The desk outline follows the space between its legs; the bed outline preserves its white pillow. Replacing the atlas requires reviewing and updating its crop coordinates and silhouette masks together.

Both the scene and atlas use `next/image` optimization. The scene uses responsive `sizes` and quality 85; the shared atlas uses `sizes="(max-width: 700px) 512px, 960px"` and quality 82. Asset URLs include the application's `/tree` base path. There is no WebGL or continuous animation loop, and no new runtime dependency was added for this artwork.

Furniture placement remains independent of the background, using the existing percentage-based center/bottom coordinates. Editing, read-only visits, keyboard controls, touch dragging, catalog selection, and visit privacy remain functional.

## Final selected generation prompts

The prompts below are the final prompts submitted to the built-in image generator for the selected files. The oak scene and atlas used the approved reference image. Each palette variant used the selected oak scene as its edit target.

### Oak room

```text
Use case: stylized-concept. Asset type: finished BITMAP background for a lightweight mobile block-world game interior, consumed directly as a scene image. Input image 1 is a STYLE AND CAMERA REFERENCE ONLY: use the middle phone's Minecraft-inspired cutaway wooden room style, crisp cubic voxel geometry and textured pixel-like oak/stone materials. Generate a NEW EMPTY ROOM, not a mockup. Composition: a nearly square 10:9 image of a spacious open-front cutaway house interior, elevated orthographic three-quarter camera from the front, same readable angle as reference. Room fills frame: back and side oak plank walls with sturdy square timber beams, a couple of square glazed windows showing trees/blue sky, warm fixed wall lanterns and small gray stone base accents. Broad clean golden oak floor occupying the lower 65 percent of the image so game furniture and characters can be placed as separate overlays. Keep a large continuous open floor, with floor/wall boundary near y=38 percent and open front edge near y=96 percent; no raised platforms on the walkable floor. Sharp blocky bevels, tactile wood grain/pixel texture, amber daylight, vivid but warm greens outdoors. No furniture: NO sofa, rug, desk, bed, plant pot, shelf, floor lamp, chairs, chests, tables, fireplace, loose decorations or characters. No UI, phones, borders, frame, interface panels, lettering, names, labels, logos, watermark. This should look like an actual attractive game map background, never SVG/vector art, never soft pastel illustration.
```

### Furniture atlas

```text
Use case: stylized-concept. Asset type: TRANSPARENT BITMAP SPRITE ATLAS for draggable furniture in the approved Minecraft-inspired block-world game. Input image 1 is a STYLE AND CAMERA REFERENCE ONLY: match middle-phone room elevated three-quarter orthographic camera, crisp cubic voxel furniture, oak pixel textures and warm lighting. Generate one transparent 4-column by 2-row atlas, landscape 2:1 canvas. EXACT eight equal square cells, no grid lines. Order left-to-right top row: 1 blocky moss-green upholstered sofa on oak frame, 2 flat square green-and-cream checkered wool rug shown in perspective, 3 small chunky oak desk with one tiny closed book built in on the top, 4 oak bed frame with moss green blanket and square white pillow. Bottom row left-to-right: 5 potted leafy block plant in square terracotta pot, 6 tall oak bookcase containing colorful block books, 7 standing oak-and-dark-metal floor lantern with square glowing amber shade, 8 completely empty transparent cell. Each object is a SINGLE isolated complete object, centered within its own equal square cell, baseline exactly at 90% of each cell height. Each object fits inside x=10..90%, y=10..90% of its own cell; preserve natural proportions and generous transparent margins. View each object from the same elevated front three-quarter angle with visible top and right faces; furniture fronts all face the camera. NO ground plane, NO floor patch, no platform under items, no neighboring walls or scene, no extra items, no characters, no text or labels, no border/grid. Output actual alpha transparency, not painted checkerboard or a solid background. Pixel-sharp rendered voxel textures, high polish, rich oak browns, green fabrics, warm amber light. These are raster game sprites, not vector icons or emoji.
```
