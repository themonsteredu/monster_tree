# 아바타 옷장 v3 저장 계약

아바타의 원본 저장소와 저장 액션은 monster_tree에 그대로 둔다. monster-site는 같은 카탈로그와 비트맵 렌더러로 읽기만 한다. 이 기능에는 DB 일괄 변환이나 학생 데이터 자동 저장이 없다.

## 버전과 호환성

- 파일명 `src/lib/avatar-v2.ts`와 기존 `parsePaperDollLook`, `normalizeLook` import 경로는 유지한다.
- `LegacyPaperDollLook`는 원래의 `kind: "paperdoll", version: 2`와 13개 선택 필드다. `LEGACY_LOOK_OPTIONS`는 출시 당시 ID만 포함한다.
- `PaperDollLook`는 canonical `version: 3`이다. 기존 필드에 `bag`, `bagColor`, `glasses`, `glassesColor`, `neckwear`, `neckwearColor`를 추가하여 총 21개 키를 가진다.
- `StoredPaperDollLook`는 두 버전의 합집합이다. 유효한 v2를 읽으면 원래의 모든 옷·색상을 유지하고 신규 부위를 `none`으로 보충하여 메모리 안에서만 v3로 반환한다.
- v2 기본 신규 색상은 가방 `sage`, 안경 `navy`, 목소품 `rose`다. 원본 객체를 변경하지 않는다.
- v2에 신규 v3 ID를 넣거나, 필드를 빠뜨리거나, 임의 키·URL·미래 버전을 넣으면 거부한다. `kind`와 `version`을 포함한 모든 필드는 own property여야 한다.
- 구형 `gallery`, `human`, `image` 아바타는 기존 `AvatarFigure` 경로를 유지한다. 이미지 기반 `gallery.accessory`를 가방 등으로 임의 해석하지 않는다. 옷장에서 명시적으로 저장하기 전에는 원본이 유지된다.

## 부위와 선택 규칙

상의·원피스, 하의, 신발, 가방, 모자, 안경, 목소품을 독립적으로 고른다. 가방·안경·목소품은 동시에 착용할 수 있고 각각 여섯 가지 색상을 가진다. 모자와 신규 소품은 `none`으로 벗을 수 있다.

`TOP_META`는 소매 길이와 하의 덮임 여부, 스타일 분류를 한 곳에서 정의한다. `changeLook`는 실제 선택과 상품 미리보기가 같은 규칙을 따르게 한다.

- 원피스를 선택해도 저장된 하의와 하의 색상은 버리지 않는다. 원피스가 보이는 동안만 하의를 가린다.
- 원피스를 입은 상태에서 하의 또는 하의 색상을 고르면 기존 옷장과 같이 맨투맨으로 전환한다.
- 헤어 또는 머리색을 고르면 사람 얼굴로 전환한다.
- 가방·안경·목소품 변경은 다른 부위를 바꾸지 않는다.

## 안전한 에셋 출시

전체 읽기 계약 `LOOK_OPTIONS`와 실제 그림 준비 상태 `AVAILABLE_LOOK_OPTIONS`를 분리한다. 메뉴는 준비된 선택지만 표시한다. 알려진 ID여도 그림이 아직 준비되지 않았으면 `isLookAvailable`가 false이므로 학생 저장 액션과 옷장 저장에서 거부한다. 읽기 호환성은 먼저 배포할 수 있다.

새 그림은 승인된 비트맵 아트와 실제 투명 배경을 사용한다. 기존 v1 atlas와 좌표는 보존한다. 새 에셋을 출시 목록에 넣기 전에 다음을 확인한다.

1. 원본의 투명 영역, 신발 사이·안경 구멍·가방 손잡이 안쪽의 잔여 배경, 단색 배경 위의 경계.
2. 공통 180×300 아바타 기준에서 어깨·팔·허리·발 위치와 원피스 길이.
3. 사람의 모든 피부색, 토끼·고양이, 기존 헤어·신발·모자와의 조합.
4. 실제 렌더링에 SVG, canvas, 런타임 이미지 처리나 지속적인 애니메이션이 없는지.
5. TREE와 SITE 목록·렌더러·에셋이 일치하는지. SITE 호환 배포 후 TREE의 신규 저장을 연다.

## 작은 화면과 테스트

옷장은 다섯 가지 큰 분류와 부위별 하위 선택을 사용한다. 상품 카드는 아바타 전체 대신 해당 부위의 그림만 표시한다. 전체 코디는 큰 미리보기에서 확인하며, 목록은 최초 12개부터 추가로 표시한다. 터치 대상은 최소 44px이고 저장·닫기·변경사항 확인·키보드 포커스 동작을 유지한다.

기본 검증은 `scripts/check-avatar-v2.cjs`, `scripts/test-avatar-actions.mjs`와 전체 TypeScript 검사다. 관리자 미리보기는 기존 `/admin/yard-preview`의 같은 옷장을 사용하고 `adminMode`에서는 학생 저장 액션을 호출하지 않는다. 실제 320px·360px 휴대폰 폭에서 소품 동시 착용과 긴 이름, 스크롤, 저장·취소를 함께 확인한다.
